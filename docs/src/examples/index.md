# Examples

Complete templates for common jobs, each from a working Craft site. Copy them, then change the markup to suit your own.

| Example | What it shows |
|---|---|
| [Cart count in a cached header](/examples/cart-count) | A personal part on every cached page |
| [Newsletter form in a cached footer](/examples/footer-form) | A Formie form that doesn’t stop pages being cached |
| [Contact form on a cached page](/examples/contact-form) | A plain Craft form, with its CSRF token refreshed |
| [Live data, refreshed every minute](/examples/live-data) | Data from outside Craft, with `ttl()` |
| [Cache status bar for development](/examples/status-bar) | See at a glance whether a page came from the cache |
